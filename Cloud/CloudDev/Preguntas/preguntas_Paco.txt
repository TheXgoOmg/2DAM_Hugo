¿Qué componente de IAM es esencial para autenticar solicitudes a través del SDK de AWS?
A. Access Key ID y Secret Access Key
B. Nombre de usuario y contraseña
C. Certificados SSL/TLS
D. Amazon Resource Name (ARN)
ANSWER: A

¿Cuál es la mejor práctica para otorgar permisos a una aplicación en EC2 para acceder a S3?
A. Almacenar claves de acceso en el código
B. Asignar un rol de IAM a la instancia de EC2
C. Crear un usuario de IAM con permisos de administrador
D. Configurar una política de bucket S3 pública
ANSWER: B

¿Cuál es la función principal de AWS X-Ray?
A. Almacenar archivos de registro (logs)
B. Cifrar datos en reposo
C. Analizar y depurar aplicaciones distribuidas (tracing)
D. Realizar pruebas de carga

¿Qué determina el costo de ejecución de una función AWS Lambda?
A. El número de líneas de código
B. Número de peticiones y duración según la memoria configurada
C. El tipo de lenguaje de programación
D. La cantidad de tráfico de red saliente únicamente

¿Cuál es la ventaja de usar variables de entorno en Lambda?
